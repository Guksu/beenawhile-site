# Been a While — site

Static pages for the Been a While iPhone app, published with GitHub Pages at https://guksu.github.io/beenawhile-site/.

- `index.html` — what the app is
- `privacy/` — the privacy policy linked from the App Store
- `support/` — help and how to reach us

**Support:** open an issue in this repository. The tracker is public, so please leave out personal information.

The app's source code lives in a separate, private repository. This repository holds only these pages.
